## 这是什么

一套给 AI 助手执行的 AIGC 全流程创作规则库。V3.0 采用**总控 + 参考资料库**架构：

- **总控** `SKILL.md`（约 490 行）：锁系统、写作铁律、写法规格、机检详单、排错手册全部内置，**不读任何外部文件也能独立跑完全流程**。
- **参考资料**：按需读取，不进常驻上下文，避免上下文爆炸。

它把 AIGC 视听创作拆成一条可复用的工业管线，解决三件事：

- **不漂移**：角色 / 场景 / 道具先锁定再进分镜，跨镜跨集一致性有据可依。
- **不返工**：七道前置锁 + 投喂前清单 + P0~P2 门禁 + 出稿机检，把错误拦在生成之前。
- **能直接投喂**：输出七段式结构化提示词，整组复制即可喂给视频模型；走 MiniMax H3 时自动转 H3 原生六段式。

**核心理念**：用户看到的是几道选择题，AI 内部跑的是上百条规则——你只说需求，锁 / 路由 / 机检全部由总控内部完成。

> 本技能**默认只出提示词与文档**，不调用任何出图工具；图由你在外部平台生成并持有。

## 七道前置锁（动手前必过）

任何一道未指定，**总控必须停下询问并把选项摆出来**——禁止默认跳过、禁止替用户推断。这是硬门，不是建议。

- **〇·0 赛道分流**：国内剧 / 海外剧 / 解说叙事 / 其他。
- **〇·1 素材来源**：原创 / 改编 / 对标爆款 / 热点速成（与赛道正交可组合）。
- **A 模型版本**：Seedance 2.5 / Seedance 2.0 / MiniMax H3，三选一（2.5 与 2.0 语法禁止混写；2.0 全面禁止首尾帧）。
- **B 画幅**：16:9 / 9:16 / 21:9，用户指定优先，禁默认 9:16。
- **C 交付形态**：离线看板 / md / 两者都给。
- **D 段缝衔接**：多段任务必锁（目标时长 ÷ 单段上限 > 1），四选一且逐项独立弹出。
- **I 画风锁**：推候选卡让你勾，卡内必含「按你的推荐走」；选定即冻结。

另有动作强度档：R1 写实克制 / R2 商业高燃（默认）/ R3 玄幻大招。

## 六阶段管线 P0~P5

- **P0 立项锁定**：七道锁 + 动作档 + 素材形态初判 + 交付契约 checklist。
- **P1 剧本门控**：Premise → 30/50/20 结构 → 因果节拍表 → 世界观与实体边界 → 剧本页；出世界锚卡、因果与关系表、角色表演档案、12 节拍情绪曲线。
- **P2 资产锁定（Asset-First）**：提取实体 → 建档确认 → 按形态产出 → 台账（CHR / AUD / PRP / SCN / U01~Uxx）。
- **P3 空间调度 + 分镜**：站位声明 + 180° 轴线 + 位移链（S0~S4 分级）。
- **P4 投喂封装**：七段式或 H3 六段式 + 六道闸门自检 + 素材接线单 + 多段衔接。
- **P5 质检**：一致性台账 + 机检详单 + 门禁复核 + 改动复验报告。

## 核心能力

- **七段式投喂**：画幅风格 → 场景资产 → 核心人物 → 站位声明 → 时间轴分镜 → 音效 → 强制禁止项；H3 走六段式且正文转英文。
- **素材形态三档**：M0 纯提示词 / M1 编号占位（默认，附接线单）/ M2 已入库；四铁律——不索要图、不因缺图阻塞、不写不存在的图号、每次声明形态。
- **防翻车写作铁律**：首镜单主体锚定、语气位必写、禁令三改法（模型对否定不敏感、对词根敏感）、摆位必入画、跨段过渡承载新信息、镜长由剧情倒推。
- **镜头规格**：15 秒完播公式、镜行三要素、空间两铁律（中全景禁 90° 正侧拍）、景别阶梯跃迁、四阶动静呼吸律。
- **打戏**：11 环动力链（压缩四要件）、六类发力、招式三件套写法、视觉三层范式、R1/R2/R3 三档。
- **情绪配方**：七大情绪 + 真假笑区分 + 控制压抑类，AU 级四区拆解（AU 编号只进内部 cue 表，投喂前转画面语言）。
- **安全转译字典**：把直白暴力词转译为受力过程，降低平台拦截风险（不承诺 100% 通过）。
- **机检与门禁**：P0 必须清零、P1 必须处理或说明、P2 必须复核留痕。
- **排错手册**：15 条以上「症状 → 病根 → 修法」，覆盖空房间开场、两张脸、道具自发光、人物凭空消失、年代穿帮等实测病灶。

## 安装

支持多技能目录的平台，把 `boge-manju/` 整个目录放到技能目录即可。

WorkBuddy 用户推荐软链方式（源码留数据盘，技能目录只留链接）：

```bash
# 1 放到你的数据盘（示例）
git clone <本仓库地址> H:/sikll/boge-manju

# 2 建立符号链接 —— 必须带 MSYS 前缀，否则 git bash 会退化成复制目录
export MSYS=winsymlinks:nativestrict
ln -s /h/sikll/boge-manju ~/.workbuddy/skills/boge-manju

# 3 验证（应回显链接目标，且 SKILL.md 可读）
readlink ~/.workbuddy/skills/boge-manju
```

## 快速开始

你只需要说一句话，总控会自动按 P0~P5 推进，中途只在七道锁处停下拉你确认：

> 「帮我做一集短剧，重生复仇题材，Seedance 2.5，竖屏，国内剧」

> 「这场打戏帮我出分镜和投喂稿」

> 「对标一下最近红果榜上那部《XXX》，我想做一部同类型的」
